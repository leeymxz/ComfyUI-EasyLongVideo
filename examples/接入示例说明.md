# 接入示例说明

本插件刻意不绑定具体视频模型：只要你的工作流满足

```
参考图/提示词 + 音频(AUDIO) → 视频节点 → 输出 mp4 的保存节点
```

就能接入。下面给两种典型接法。

---

## 方案 A：MiniMax H3 Ref2VA 工作流

如果你已经装好 H3 的 ComfyUI 节点与模型（原版插件的用户可以直接迁移）：

```
[Load Audio]──audio──▶[EasyLVUnified]──original_audio_padded──▶ H3 的 Audio 输入
                                      └─segment_brief──▶（提示词扩写节点）──▶ H3 的提示词输入
                                      └─generation_frames──▶ H3 的 length/num_frames
[LoadImage 参考图]──────────────────────────────────────────▶ H3 的参考图输入
H3 视频节点──▶ [VHS Video Combine]（filename_prefix 接 filename_prefix，save_output 开启）
```

要点：

1. `frame_align` 选 `h3`，`fps` 选 `24` —— generation_frames 自动满足 H3 的 5+17k、≥124 约束；
2. 唱歌模式建议 `widest_framing = full shot`（允许全身镜头变化）；
3. 扩写规则可继续沿用你已有的 V5 规则文本：`segment_brief` 里已包含
   「模式 / 镜头方案 / 表演节奏」三行协议，与原版格式兼容。

## 方案 B：其他"图 + 音频 → 视频"模型（Wan / Hunyuan / 自定义）

```
[EasyLVUnified].original_audio_padded ──▶ 你模型的音频输入
[EasyLVUnified].segment_brief ──▶ 任意文本处理/LLM 节点 ──▶ 你模型的提示词输入
[EasyLVUnified].generation_frames ──▶ 你模型的帧数输入（若支持）
输出节点保存为 mp4（任何能落盘 mp4 的保存节点均可）
```

## 面板操作速查

| 操作 | 位置 |
| --- | --- |
| 打开面板 | 节点上的「📋 分段审核面板」按钮；分析完成后也会自动弹出 |
| 试听某段 | 段卡片里的播放器 |
| 修改镜头简报 | 直接编辑简报文本框，失焦自动保存 |
| 合并两段 | 「并入下一段」（合并后不能超过最长段时长） |
| 重新生成某段 | 「重做本段」（使用当前画布快照） |
| 确认分段 | 底部「✓ 保存并确认」 |
| 顺序生成 | 底部「▶ 开始顺序生成」（会快照当前画布并选择输出节点） |
| 只合成不生成 | 「🎞 仅重新合成」（用已完成的段拼片） |
| 换输出节点 | 底部右侧下拉（默认自动选中 VideoCombine 类节点） |

## 常见问题

**Q：点开始生成提示"请选择视频输出节点"？**
工作流里没有识别到输出节点，或选中的节点没有保存视频。确认输出节点开启了
保存（如 VHS 的 `save_output`），并在下拉里手动选择它。

**Q：生成到一半失败？**
面板会显示失败段。修复工作流问题后点该段「重做本段」，其余段不受影响。

**Q：没有 ffmpeg，成片怎么办？**
各段视频已按顺序存放在项目目录。安装 ffmpeg（或确认 ComfyUI 能找到它）后点
「仅重新合成」；或按 `work/如何手动合成.txt` 里的清单导入剪辑软件手工拼接。

**Q：唱歌切点不准？**
1) 接入 `vocals`（UVR 等工具分离的人声）；2) 安装 faster-whisper 后重新分析；
3) 在面板里试听并「并入下一段」合并问题段。
